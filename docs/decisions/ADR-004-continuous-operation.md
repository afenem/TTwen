# ADR-004: Sürekli çalışma

Karar:
Kullanıcı uygulamayı kapatana kadar görev motoru çalışır.

Kapsam:
köy yönetimi, şablon değerlendirme, simülasyonlar, farm/vaha/Natar görevleri ve durum güncelleme.

Kullanıcı talebi doğrultusunda anti-detection amaçlı rastgele gecikme, kendini silme, gizli mod ve otomatik kapanma tasarlanmaz.
