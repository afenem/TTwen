# ADR-001: Dil ve framework

Karar:
TTwen C# + .NET 10 + WinUI 3 / Windows App SDK ile geliştirilecektir.

Neden:
Windows masaüstü hedefi, güçlü tip sistemi, büyük çözüm yönetimi, modern native UI ve Playwright .NET desteği.

Python + PySide yalnızca hızlı prototip olarak değerlendirildi. Nihai uygulama çok modüllü ve uzun süre bakım yapılacak bir Windows çözümü olacağı için C#/.NET'e geçildi.
