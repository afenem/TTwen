# TTwen sözlüğü

Adapter: Dış sistem ile iç model arasında çeviri yapan katman.
Application: İş akışlarını yöneten katman.
Domain: Oyunun anlamlı kavramlarını temsil eden katman.
Oasis: Vaha.
Combat Simulator: Savaş sonucunu tahmin eden motor.
Profit: Ekonomik net sonuç.
Rule Set: Sunucunun oyun kuralları.
Template: Tekrar kullanılabilir köy/bina planı.
Reader: TTWars HTML'inden veri okuyan bileşen.
Mapper: Ham veriyi domain nesnesine dönüştüren bileşen.
ViewModel: UI sunum durumunu taşıyan sınıf.
Operation: Tek bir anlamlı işlem.
Job: Birden fazla operation içeren görev.
